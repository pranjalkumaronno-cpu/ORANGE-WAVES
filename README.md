## ✨ Features & Track Breakdown

### 🧮 1. Math Engine (Core Utility)
* **Stream-Specific Marks Calculator:** Dedicated scoring algorithms tailored for **Commerce, Science, and Arts** evaluation metrics.
* **Smart Calculator:** Built-in computations handling basic operations (`+`, `-`, `*`, `/`), powers, and remainder loops without performance overhead.
* **Math Lab Modules:** Specialized components supporting trigonometry and foundational analytical mathematics.

### 📝 2. Language & Study Processor
* **Contextual Notes:** An organized, distraction-free environment for structured digital note-taking.
* **Grammar Processor:** Text parsing engine to scan documents, flag formatting issues, and improve syntax.
* **Automated Flashcards:** Convert key phrases and vocabulary from active notes directly into study-ready digital flashcards.

### 📅 3. Dynamic Scheduler
* **Adaptive Timelines:** A dual-purpose schedule module balancing intensive academic preparation with physical health.
* **Study & Fitness Tracker:** Automated alerts encouraging micro-breaks, mobility intervals, and workout logs to fight student burnout.

## 🚀 Getting Started

### Prerequisites
Ensure you have the following installed locally:
* Node.js (v18+) or Flutter SDK (depending on setup)
* Git

### Installation & Local Setup
1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd orange-waves
   ```

2. **Install dependencies:**
   ```bash
   npm install   # or appropriate dependency command
   ```

3. **Configure Environment Variables:**
   Create a `.env` file in the root directory and append your local development environment keys.

4. **Launch Local Development Server:**
   ```bash
   npm start     # or project run command
   ```

## 🤝 Contribution Guidelines

We are building this project under a **shared equity/co-founder framework**. To keep the main branch stable, please follow this git workflow:

1. **Create a feature branch** from `main` (`git checkout -b feature/amazing-feature`).
2. **Commit your modifications** with clear, descriptive messages (`git commit -m 'feat: added science marks calculation engine'`).
3. **Push the branch** to origin (`git push origin feature/amazing-feature`).
4. Open a **Pull Request** for review.
